# 金叉死叉

> 这份讲「信号」这个东西的数学结构。回测部分（持仓、未来函数、绩效指标）Day 21 之后另建文件。

## 一、定义

- **金叉**：快线（ma5）从下方**上穿**慢线（ma20）
- **死叉**：快线从上方**下穿**慢线

直觉：快线代表近期，慢线代表中期。快线跑到慢线上方 = 近期比中期强。

## 二、先分清「状态」和「事件」—— 这一节是核心

**状态**：今天 ma5 在 ma20 上方吗？

    s_t = 1 if ma5_t > ma20_t else 0            ...(6)

它是一整列 0/1，描述每一天的**位置关系**。状态会**持续**很多天。

**事件**：今天**发生**了穿越吗？

    c_t = s_t - s_{t-1}                         ...(7)

它是状态的一阶差分，只可能取三个值：

| 值 | 含义 |
|---|---|
| `+1` | 今天从 0 变 1 = 金叉（买卖点就在这一天） |
| `-1` | 今天从 1 变 0 = 死叉 |
| `0` | 状态没变（绝大多数日子） |

**为什么必须分成两个东西**：交易只发生在穿越那一天、只发生一次。
- 拿 `s_t == 1` 去下单 → 你会从金叉那天起**每天**都买一遍
- 拿 `c_t == 1` 去下单 → 只在穿越那天买一次。这才是对的

数学上，`c_t` 就是带符号的事件指示函数 `s_t - s_{t-1}`。

## 三、diff 的性格

- 第一行一定是 **NaN** —— 和第 15 天 `pct_change` 完全同一个原因：第 0 天没有「前一天」
- `diff` 只做减法，不乘任何系数。0 变 1 就是 1。

## 四、前瞻收益（Day 20 用）

要问「金叉之后涨不涨」，就得把「今天**之后** k 天的累计收益」搬到今天这一行来：

    fwd_k(t) = P_{t+k} / P_t - 1

用日收益率表达（小收益下的近似，因为收益率不能直接相加，见 `累计收益与净值曲线.md`）：

    fwd_5(t) ≈ r_{t+1} + r_{t+2} + ... + r_{t+5}

代码上让数据「往右看 k 天」，靠的是**负数的 shift**：正 shift 把过去搬到现在，负 shift 把未来搬到今天。

⚠️ 这里已经埋了一颗种子，现在先记住结论，Day 22 展开：

**「研究时用未来数据」和「交易时用未来数据」是两件完全不同的事。**
- 研究 / 统计：应该用 —— 你就是要回头看「当时买了后来会怎样」
- 交易：绝对不能用 —— 那叫**未来函数**，回测里最致命的错误

所以 `fwd` 这种列，**只能进统计，不能进交易逻辑**。

## 五、你的数据会给出的自查数字

`sh600519_qfq.csv`（418 行，到 2026-09-21），ma5 上穿记 +1、下穿记 -1：

- 前 19 行信号恒为 0：因为 `ma20` 是 NaN，而 **NaN 参与任何比较都是 False**
  （`NaN > x` 和 `NaN < x` 都是 False）→ 那一步把预热期悄悄变成了 0

⚠️ 这些数字会随数据截止日变（你重新取数就会变），别当成固定值。

## 六、坑

1. **`cross != 0` 会把 NaN 也算进去**。第一行是 NaN，而 `NaN != 0` 在 Python 里是 `True`。
   所以 `cross[cross != 0]` 的第一个元素是 NaN，不是事件。
   → 分开写：`cross == 1` / `cross == -1`，或者先 `fillna(0)`。
2. **NaN 参与比较永远 False**（第五节那条）。预热期静默变 0 —— 在信号层面无所谓，
   在**持仓层面**（Day 22）要小心，那会变成「自动空仓」。
3. 金叉死叉是**均线的函数**，不是独立信息。均线滞后，金叉必然滞后。
   Day 20 的统计要回答的就是：滞后了这么多之后，还剩多少？
4. ma5 和 ma20 必须用**同一种价格**算。
