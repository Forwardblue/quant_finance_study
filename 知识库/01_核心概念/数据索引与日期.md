# 数据索引与日期

> **一句话**：把「日期」从一列普通文本，变成 DataFrame 的行标签（索引）。
> 这份笔记只管「读进来的数据怎么摆」。均线的算法在 `移动平均线.md`，这里不重复。

## 一、为什么非做这一步

`pd.read_csv` 读进来的 `date` 是**字符串**（`str`），不是日期对象。Day 11 撞到的三条后果：

| 现象 | 原因 |
|---|---|
| `df['date'] > '2026-01-01'` 能跑，但和 `datetime` 比就 `TypeError` | 字符串只能和字符串比 |
| 画图时 x 轴是 0,1,2,3… 序号 | 日期还不是行标签，matplotlib 只看到序号 |
| `df['open'].index` 打出 `RangeIndex(start=0, stop=418, step=1)` | 同上 |

## 二、两步

```python
df['date'] = pd.to_datetime(df['date'])   # 第 1 步：字符串 → 日期对象
df = df.set_index('date')                 # 第 2 步：把 date 列提升为行标签
```

两个必须记住的点：

1. **两行都要写 `df = `**。`set_index` 默认不原地改（`inplace=False`），不接返回值，结果直接丢掉。
2. **`set_index` 之后，`'date'` 不再是列**。这时 `df['date']` 会 `KeyError`；它已经变成 `df.index`。

## 三、怎么检查自己有没有做对

```python
print(df['open'].index)   # RangeIndex → DatetimeIndex
print(df['open'].head())  # 每行前面顶着的就变成日期了
```

Day 11 的真实输出（截取）：

```
# 做之前
RangeIndex(start=0, stop=418, step=1)
0    1435.70
1    1407.91
Name: open, dtype: float64

# 做之后
date
2025-01-02    1435.70
2025-01-03    1407.91
Name: open, dtype: float64
```

## 四、做完之后，索引会自己跟着走

```python
ma5 = df['open'].rolling(window=5).mean()
```

`ma5.index` 和 `df.index` 完全一样 —— `rolling` 是逐行算出来的，行标签原样带过来。
所以画图时不用手动对齐日期：`plt.plot(df['close'])` 和 `plt.plot(ma5)` 自动落在同一条时间轴上。
