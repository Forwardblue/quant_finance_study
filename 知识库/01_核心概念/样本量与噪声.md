## 一、【现在必读】问题的形状

你手里有 23 个数 —— 每次金叉之后 5 个交易日的收益（%）：

    0.4322  -1.0333  -4.2615   4.5459  -4.0879  -1.1802  -1.4863  -4.5683
   -0.9447   0.8960  -0.0643   3.4101   0.9144  -0.1481  -1.2018   0.4001
   -0.4441   2.0259  -3.9851   0.0715   7.6650  -2.7916   4.4702

求和 = `-1.3659`，除 23：

    x̄ = -1.3659 / 23 = -0.05939%

而「随便哪天买入、持有 5 天」的平均是 `+0.05980%`。

    x̄ - 基线 = -0.05939% - 0.05980% = -0.1192%

**问题**：这 -0.1192% 说明「金叉之后会跌」，还是只是这 23 次运气不好？

这个问题的答案是**不靠直觉，靠算**。下面就是怎么算。

---

## 二、【现在必读】样本 ≠ 总体

把你两年来实际发生过的 23 次金叉，看成一个**样本**。你真正想知道的是：

> **「金叉」这件事，在任何时间、任何股票上，平均有没有超额收益？**

那是**总体**。你永远看不到它 —— 你只看到 23 次。

用符号：

| 符号 | 含义 | 你知不知道 |
|---|---|---|
| `μ` | 总体的真实均值（金叉的"真本事"） | **永远不知道** |
| `σ` | 总体的真实标准差 | **不知道** |
| `x̄` | 样本均值 = `-0.05939%` | 算得出来 |
| `s` | 样本标准差 = `3.0428%` | 算得出来 |
| `n` | 样本量 = `23` | 知道 |

**`x̄` 是 `μ` 的估计量（estimator）。** 注意"估计量"这个词：它是个**随机变量**，不是个数——换个样本（换只票、换时间段），它就变。它只给你一个数，是因为你恰好只抽了一次。

---

## 三、【现在必读】关键一步：平均值本身是随机变量

设 `X₁, X₂, ..., Xₙ` 是 n 次金叉的 5 日收益，独立同分布，均值 `μ`、方差 `σ²`。

    x̄ = (1/n) · Σ Xᵢ

求它的期望和方差：

    E[x̄] = (1/n) · Σ E[Xᵢ] = (1/n) · nμ = μ          ← 无偏

    Var(x̄) = (1/n²) · Var(Σ Xᵢ)
           = (1/n²) · Σ Var(Xᵢ)        ← 独立性 ⟹ 协方差为 0
           = (1/n²) · nσ²
           = σ² / n                                         ...(1)

**式 (1) 是这一整份笔记的根。** 它说：平均值的方差，是单个观测方差的 `1/n`。

⚠️ 注意这里是**方差**除以 n，不是标准差除以 n。所以标准差要**开根号**：

    sd(x̄) = σ / √n                                          ...(2)

**这个 √n 你已经见过一次** —— Day 17 的「方差可加、标准差不可加」是同一个原理：
n 个独立观测的方差相加得 `nσ²`，开根号才有 `√n`。不是新东西，是同一条事实的第二次出现。

---

## 四、【现在必读】标准误：σ 不知道，用 s 顶上

式 (2) 里的 `σ` 是总体的，你看不到。于是用样本标准差 `s` 代进去：

    SE = s / √n                                             ...(3)

**这就是「标准误」（standard error）的定义。** 它不是新概念，就是「`x̄` 这个估计量的标准差」——只不过 `σ` 换成了 `s`，所以带一点估计误差（n 越小，误差越大，见第十节）。

代入你的数：

    SE = 3.0428% / √23 = 3.0428% / 4.7958 = 0.6345%

**读法：如果换 23 次金叉重来一遍，你算出的 `x̄` 大概会在 ±0.63% 的范围里晃。**

---

## 五、【现在必读】标准差 vs 标准误 —— 这两个必须分清

| | 符号 | 衡量什么 | 你的数字 | 变大/变小取决于 |
|---|---|---|---|---|
| **标准差** | `s` | **单个**观测有多散 | 3.0428% | 这只票本身的波动 |
| **标准误** | `SE` | **平均值**有多不稳 | 0.6345% | 样本量（`1/√n`） |

一句话：

> **标准差描述「你看到的东西有多乱」，标准误描述「你算出的结论有多不牢」。**

想降低标准差：换一只波动小的票（改变了研究对象的性质，通常是坏事）。
想降低标准误：**多要样本**（不改研究对象，只是看得更清楚）。

这个区别决定了你后面所有决策：**觉得结论不可靠时，唯一正确的动作是加样本，不是换指标。**

## 六、【现在必读】把 23 个数手算一遍（对答案用）

**均值**

    总和 = -1.3659        （上面那 23 个百分比直接相加）
    x̄   = -1.3659 / 23 = -0.05939%

**样本标准差**（`n-1` 分母，pandas `.std()` 的默认）

    s = √( Σ(xᵢ - x̄)² / (n-1) ) = 3.0428%

抽一项看：

    x₁ = +0.4322,  x₁ - x̄ = 0.4322 - (-0.0594) = 0.4916
    (0.4916)² = 0.2417          ← 23 个这样的数加起来，再除以 22，再开根号

最大的那一项是 `+7.6650`，离均值 `7.7244`，平方后 `59.67` —— **它一个就占了总平方和的 29%**。
这就是 23 个样本的脆弱之处：一个异常值能大幅改变 `s`，进而改变 `SE`。

**标准误**

    SE = 3.0428% / √23 = 0.6345%

**对零的 t 值**

    t = x̄ / SE = -0.05939 / 0.6345 = -0.094

**对基线的 t 值**

    t = (x̄ - 基线) / SE = -0.1192 / 0.6345 = -0.188

两个都不到 1。第二节会讲「2」是什么。

---

## 七、【现在必读】中心极限定理：为什么可以拿「2」当门槛

`x̄` 的分布，在 `n` 大时近似正态：

    x̄ ≈ N( μ, σ²/n )                                        ...(4)

这就是中心极限定理（CLT）：**不管单个 `Xᵢ` 是什么分布**（你的 23 个收益明显不正态，有 `+7.67` 也有 `-4.57`），只要独立同分布、`n` 够大，平均值就近似正态。

标准化之后：

    z = (x̄ - μ) / SE  ≈  N(0, 1)                            ...(5)

于是「`x̄` 偏离 `μ` 超过 2 个 SE」的概率约 5%。

**⚠️ `n=23` 算不算"够大"？** 勉强。所以严格讲该用 **t 分布**而不是正态：

| | 临界值（双侧 95%） |
|---|---|
| 正态 `z` | 1.960 |
| t 分布，`df = 22` | **2.074** |

差别不大，但既然只有 23 个样本，用 2.074 更稳。**"2" 这个门槛就是这么来的**，不是拍脑袋。

---

## 八、【现在必读】置信区间：把你的结论写成一条区间

把式 (5) 反解：

    μ ∈ x̄ ± t · SE                                          ...(6)

代入：

    -0.05939% ± 2.074 × 0.6345%
    = -0.05939% ± 1.3159%
    = [ -1.375% , +1.256% ]

**这是你能说的话**：「金叉后 5 日的真实平均收益，95% 置信区间是 -1.38% 到 +1.26%。」

**这不是你能说的话**：「金叉后平均跌 0.06%」。

区间宽 2.6 个百分点，而且**跨过 0**。跨过 0 的意思是：**"金叉之后平均不涨不跌"这个假设，完全在这份数据能解释的范围内。**

对比一下：如果你有 2500 个样本，`SE` 会缩到 `0.06%`，区间宽度只剩 0.25 个百分点，那时候才能说点硬话。

## 九、【第 8 周再读】看不出 ≠ 没有（这是最容易犯的错）

假设检验有两类错误：

| | 真实情况：没效应 | 真实情况：有效应 |
|---|---|---|
| **你说"有"** | ❌ 第一类错误（假阳性），概率 `α`，通常设 5% | ✅ 正确 |
| **你说"没有"** | ✅ 正确 | ❌ 第二类错误（假阴性），概率 `β` |

**功效（power）= 1 - β = 「真有效应时，你能测出来的概率」**

你的情况：假设金叉真的有 `0.119%` 的超额收益（`t = 0.188`）。

    power = P( |z + 0.188| > 1.96 ) ≈ 5.4%

**换句话说：即使金叉真有这个本事，你这个 23 样本的实验也只有 5% 的概率能发现它，95% 的概率会漏掉。**

所以「p > 0.05」或「t < 2」**不能**推出"没有效应"。它只推出：**这个实验没有能力回答这个问题**。

这在统计上叫「**缺乏功效**（underpowered）」。量化里大量"我测了，没用"的结论，都是这个毛病。

## 十、【第 8 周再读】要多少样本才够？（反向用 √n）

想让 `SE` 小到能分辨一个效应 `Δ`，需要：

    n = ( z · s / Δ )²                                      ...(7)

你要分辨的是 `Δ = 0.1192%`，`s = 3.0428%`：

    n = ( 1.96 × 3.0428 / 0.1192 )² ≈ 2500

你的金叉频率：`23 次 / 2.68 年 ≈ 8.6 次/年`

    → 需要 2500 / 8.6 ≈ 290 年

**这就是单只票回测没说服力的根本原因。** 不是方法不对，是样本量差两个数量级。

三个解法，按可行性排：

1. **横截面**：一天看几百只票，同一天的金叉算不同样本（但要注意它们高度相关，不能当独立）
2. **拉长历史**：十年、二十年（能到 4-5 倍，仍旧不够）
3. **找更强的信号**：`Δ` 大 10 倍，`n` 只需要 1/100。**这是唯一可能真正解决的问题**

第 3 条的口径值得记住：**要找的不是"有点用"的信号，是"强到能被 23 个样本看见"的信号。** 这也是为什么真正的量化研究都在找很极端的异象。

---

## 十一、【可以跳】分辨率：你这把尺子的最小刻度

由式 (6)，`n` 个样本能分辨的最小效应约为：

    Δ_min ≈ 2 · SE = 2 × 0.6345% = 1.27%                    ...(8)

**任何小于 1.27 个百分点的效应，这 23 个样本都测不出来。**

你要找的是 0.12%，只有刻度的 `1/10`。

用尺子打比方：刻度 1 厘米的尺子量两根头发谁更粗，差 0.02 厘米。你读不出来 —— **不代表头发一样粗，代表尺子读不了这么细。**

---

## 十二、【第 7 周再读】多重比较：为什么「挑最好的参数」是作弊

如果你试 20 组不同的均线参数，每组做一次 5% 水平的检验，那么**至少有一组"显著"**的概率是：

    1 - 0.95²⁰ = 64%

即使这 20 组参数全都毫无用处，你也有 64% 的概率找到一组"看起来很棒"的。

这就是「**数据窥探**（data snooping）」/「**过拟合**」。第 7 周你要做参数扫描 `(5,20) / (5,10) / (10,30) / (20,60) / (30,120)` —— **扫完之后挑收益最高的那组，等于给自己制造了一个 64% 的假阳性。**

正确做法（第 8 周才讲）：**用一段数据选参数，用另一段完全没看过的数据验证。**

## 十三、【现在必读】坑

1. **标准差和标准误混用**。`s` 描述单个观测的散度，`SE` 描述均值的稳定度。报"波动率"用 `s`，报"这个平均值靠不靠谱"用 `SE`。
2. **`n` 用的是「有效样本数」，不是「行数」**。你有 670 行数据，但金叉只有 23 次 —— 这里 `n = 23`。用 670 去除，`SE` 会小 5.4 倍，结论直接假掉。
3. **`n=23` 时该用 t 而不是 z**。差别不大（2.074 vs 1.960），但方向要知道：小样本的区间**更宽**。
4. **重叠窗口会高估样本量**。如果金叉相隔只有 1-2 天，它们的 5 日窗口大量重叠，实际上不独立，"有效 n"比 23 还小。
5. **`p > 0.05` 不等于"没效应"**，可能只是功效不足（第九节）。
6. **`n` 小的时候，`s` 本身也不稳**。你的 `s=3.04%` 被 `+7.67%` 那一个值拉高了（占总平方和 28%），去掉它 `SE` 会明显变小 —— 这说明连误差估计本身都不牢。
