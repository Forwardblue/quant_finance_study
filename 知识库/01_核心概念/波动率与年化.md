# 波动率与年化

> 承接前两份。这份讲「风险」这个指标的数学，以及为什么它要乘 √252。

## 一、波动率是**收益率**的标准差，不是价格的

价格的波动幅度取决于价格水平，10 元的票和 1000 元的票没法直接比。
收益率已经除掉价格了（`日收益率.md` 讲的无量纲），所以它的标准差可以横向比较 —— 这才是波动率。

    σ = sqrt( Σ (r_i - r̄)² / (n - 1) )          ...(4)

- `r̄` 是窗口内收益率的算术平均
- 分母是 `n - 1` 不是 `n`：这是**样本**标准差的写法，pandas `.std()` 默认就是它（`ddof=1`）
- 差多少：你这 662 行的全样本 `Series.std()` = 0.01476002，`numpy.std(ddof=0)` = 0.01474885。
  只差 0.08%（小数点后第 5 位）—— 不大，但两边默认值不一样，混用就会莫名其妙对不上

## 二、20 日滚动

`rolling(20).std()` = 对每一天，取「它和它前面 19 天」共 20 个收益率，套式(4)。
和均线是同一个 `rolling` 机制，所以开头同样是 NaN，原因也一样。

但**开头是 20 行 NaN，不是 19 行**。因为输入是 `ret`，而 `ret` 的第 0 行本来就是 NaN：
`rolling(20)` 在第 0~19 行上的窗口全都含这个 NaN，整格作废；第一个干净的窗口是第 1~20 行，
落在**第 20 行**。两个「数据不够」叠在一起，就恰好吃掉一整个窗口长度。

（均线算在 `close` 上，`close` 没有空洞，所以 MA20 的开头是 19 行。差别只在 `ret` 多了一个 NaN。）

## 三、年化：为什么乘 √252 而不是 ×252

关键一步：**方差可以按时间相加，标准差不能。**

假设日收益率彼此独立、方差相同（常用近似）：

    日方差      = σ_d²
    年方差      = 252 × σ_d²          ← 方差线性累加
    年化波动率  = sqrt(年方差) = σ_d × √252     ...(5)

`√252 ≈ 15.87`，所以年化数字大约是日数字的 **16 倍**。
你的数据实测（20 日窗口最后一天）：日 0.008215 → 年化 0.130405。

为什么不能直接 ×252：σ 身上带着平方根。你乘的是天数，而天数作用在**方差**上，最后才开根号。

⚠️ 对照记一下：**年化收益不是这么算的**。收益是复合的，指数是 `252 / 天数`，见 Day 24。
两个年化公式长得很像，来源完全不同，别串。

## 四、252 是什么

A 股一年大约 252 个交易日：
`365 - 周末 104 天 - 法定节假日` ≈ 250 上下。行业惯例取 252，美股也用这个数。

它的意义是「把日单位换算成年单位的比例系数」，不是真去数了 252 天。

用你自己的数据自查一下这个系数靠不靠谱：

    662 个交易日 ÷ 996 个自然日 × 365 ≈ 242.6 天/年

量级是对的（偏小是因为那段时间假期多）。近似的东西就该这样自查，别当成常数背下来。

## 五、坑

1. **不是价格的 std**。`df['close'].std()` 得到的是「价格波动了多少元」，那不是波动率。
2. `ddof`：pandas 默认 1，numpy 默认 0。不定就写清楚。
3. 两个年化公式别混（上面第三节那条）。
4. 波动率描述的是**已经发生**的事。它常被当作「风险」的代理指标，但它不预测未来 ——
   和均线一样，它是对过去的一种压缩。

## 七、代码

完整脚本：`python_study/daily_return.py`（注释为「这里开始算波动率,并做了年化」那一段）。

```python
df["20sigma"] = df["daily_return"].rolling(window=20).std()
df["20sigma_annual"] = df["20sigma"] * math.sqrt(252)
```

实测：末端 `0.008215` → 年化 `0.130405`。窗口内最小 `0.005263`（2025-12-23，年化约 8.4%），
最大 `0.044451`（2024-10-18，年化约 70.6%）。
同一只票、同一年，年化波动率能从 8% 跳到 70% —— 这就是「波动率不是常数」。

预热期多长只能 print 出来数，不能看图。
