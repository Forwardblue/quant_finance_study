# 累计收益与净值曲线

> 承接 `日收益率.md`。这份讲「多天的收益怎么正确合起来」。

## 一、先记住：收益率不能相加

Day 15 你会拿到一列日收益率。想算「这段时间总共赚了多少」，第一反应是 `sum()` —— 那是错的。

- 涨 10% 再跌 10%：`1.10 × 0.90 = 0.99`，亏 1%，不是 0
- 你的数据实测：`sum(ret) = -0.0774`，而真实累计是 `-0.1064`。**3 个百分点凭空没了**

原因：百分比是相对「当初的本金」说的，而本金每天都在变。

## 二、正确的合起来的方式：连乘

净值（net asset value，NAV）的定义：

    NAV_0 = 1
    NAV_t = NAV_{t-1} × (1 + r_t)                ...(2)

展开：`NAV_t = (1+r_1)(1+r_2)...(1+r_t)`。
把每天的涨幅当成「今天相对昨天是几倍」，一路乘下去。

## 三、最重要的一条恒等式（Day 16 验收就是它）

把 `r_t = P_t / P_{t-1} - 1` 代进 (2)，会**望远镜式地一路约掉**：

    (1+r_1)(1+r_2)...(1+r_t)
    = (P_1/P_0)(P_2/P_1)(P_3/P_2)...(P_t/P_{t-1})
    = P_t / P_0                                  ...(3)

所以：**净值曲线的末端数值 = 期末价格 / 期初价格**（假设 1 元本金、期间无分红）。

推论（很值得记住）：**净值曲线和价格曲线形状完全一样**，差别只在纵轴刻度。
一条从 1 开始，一条从 `P_0` 开始。画在一起会完全重合。

## 四、手算（对答案用）

| 日期 | close | r_t | 1 + r_t | NAV_t |
|---|---|---|---|---|
| 2025-01-02 | 1401.79 | NaN | — | 1.000000 |
| 2025-01-03 | 1389.54 | -0.008739 | 0.991261 | 0.991261 |
| 2025-01-06 | 1356.57 | -0.023727 | 0.976273 | 0.967741 |

验算：`1356.57 / 1401.79 = 0.967741` ✓ 和 NAV 对上。

## 五、第一天那个 NaN 怎么处理

`NAV_0 = 1` 是**定义**出来的，不是算出来的（第 0 天没有收益率）。
所以代码里要把第一个 NaN 当成 0 —— `1 + 0 = 1`。

因为 (2) 是**递推式**：一个 NaN 会污染它之后的所有值。这和均线那种「只看窗口内」完全不同 ——
加法/乘法沿着序列一路传播，错一个，后面全错。

## 六、坑

1. `sum()` 代替 `cumprod()`。波动越大，错得越离谱。
2. `prod()` vs `cumprod()`：`(1+r).prod()` 只给最终一个数；画图要的是**一整条曲线**，用 `cumprod()`。
3. NaN 忘了填 1，或者填了 0 —— 填 0 的话整条曲线全变 0。
4. 净值曲线**看起来像**价格走势，很容易误以为它是「策略好坏」的证据。不是：
   单一股票的净值曲线和买入持有完全等价（这就是 (3) 式说的），**它不含任何策略信息**。
   有信息的是「策略净值 vs 基准净值」的差，那是 Day 27 的事。
