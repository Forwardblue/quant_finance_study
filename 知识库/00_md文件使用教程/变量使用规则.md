1. 变量名只能包含字母、数字和下划线。变量名能以字母或下划线
打头，但不能以数字打头。例如，可将变量命名为
message_1，但不能将其命名为 1_message。
2. 变量名不能包含空格，但能使用下划线来分隔其中的单词。例
如，变量名 greeting_message 可行，但变量名 greeting
message 会引发错误。
3. 不要将 Python 关键字和函数名用作变量名。例如，不要将
print 用作变量名，因为它被 Python 留作特殊用途（请参见附
录 A.4）。
4. 变量名应既简短又具有描述性。例如，name 比 n 好，
student_name 比 s_n 好，name_length 比
length_of_persons_name 好。
5. 慎用小写字母 l 和大写字母 O，因为它们可能被人错看成数字
1 和 0。
