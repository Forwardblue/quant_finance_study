## 已解决（7）

- [x] #1 · 09-20 · `.rolling` / `.mean` / `.round` 是方法还是函数？
  → **方法**依附对象（`s.mean()`），**函数**直接调（`pd.concat()`）。`s.rolling(window=5)` 先造出一个窗口对象、再对它 `.mean()` —— 这叫链式调用。

- [x] #3 · 09-20 · 只读懂了 SMA / EMA 的算法，不知道怎么用
  → 解决（09-23）：默写 + Day 11–13 落地 —— 在真实股价上算了 MA5 / MA20 / MA60，还包成了 `get_ma(code)` 函数，换只票就能跑。
  → 真正卡住的不是算法，是数据：列名（open / close）、索引（set_index）、类型（str vs datetime）。算法那部分其实一天就会了。

- [x] #5 · 09-21 · `np.array` 是干嘛的？
  → 三种容器：列表 `[]` 长度可变、能混类型，靠指针装对象；数组 `ndarray` 长度固定、类型必须统一，所以算得快；元组 `()` 两者都不可变。
  → 所以 `np.array(list)` 只是个**类型转换器**，转完之后的向量化运算由数组自己提供。

- [x] #7 · 09-21 · 为什么「100 + 一条路径」就是随机游走？
  → **广播**：`100` 先被扩成和路径同形状的数组，再逐元素相加。`cumsum` 是逐日累加，所以 起点 100 + 累计增量 = 游走。
  → 验算：`(100 + np.cumsum(steps))[i] == 100 + steps[:i+1].sum()`

- [x] #8 · 09-22 · `pd.DataFrame({"prices": prices})` 里的花括号是什么？
  → **字典**。符号：`{}` 字典 / `[]` 列表 / `()` 元组。字典靠**键**取值，列表和元组靠整数下标；字典能增删改，但**键必须不可变**。
  → 例：`{"600519": "贵州茅台", "000001": "平安银行"}` —— 其中一个键值对就是 `"600519": "贵州茅台"`。

- [x] #9 · 09-23 · rolling 时日期从 9-19 跳到 9-23，中间几行没有，怎么算？
  → **`rolling` 只数「行」，完全不看索引里的日期。** `rolling(5)` = 往前抓 5 行，不管这 5 行横跨了几天。
  → 所以 A 股说的 MA5 永远是**5 个交易日**，不是 5 个自然日。周末、节假日、停牌一律跳过，一行都不补。
  → 验算（自己的数据）：2026-05-06（五一后第一个交易日）的 MA5 取的是 4/27、4/28、4/29、4/30、5/6 —— 自然日跨度 9 天。全表相邻日期差 ≥3 天的地方有 89 处，最长 11 天（2026-02-24，春节）。
  → 真要看自然日窗口：索引已经是 DatetimeIndex 了，`df['close'].rolling('5D').mean()` 直接能跑（时间窗口 / offset）。金融里基本不用。

- [x] #10 · 09-23 · `type(x)` 和 `x.dtype` 有什么区别？
  → `type(x)` 回答「**这是什么对象**」：`type(df)` → `pandas.core.frame.DataFrame`，`type(df['close'])` → `pandas.core.series.Series`。
  → `x.dtype` 回答「**里面的元素是什么类型**」：`df['close'].dtype` → `float64`。
  → DataFrame 没有 `.dtype`，只有 `.dtypes`（每列一个，因为一列一个类型）。要查列的类型，永远用 `df.dtypes`。
